# API reference

Base path `/v1`. Interactive docs: `http://localhost:3000/docs` (Swagger UI). Machine-readable: [`openapi.json`](openapi.json) — regenerate with `pnpm --filter @meddexa/api openapi`.

Conventions
- JSON everywhere; errors are `{ statusCode, error, message, code?, details? }` (`VALIDATION_ERROR` lists `details[].path/message`).
- Authentication: `Authorization: Bearer <accessToken>` (15 min). Refresh with `POST /auth/refresh` (rotating, 30 days). Public endpoints accept an optional token.
- Prices: pass `currency` (EUR, HUF, PLN, CZK, RON, GBP, CHF, SEK, DKK, NOK, BGN, UAH, USD). Converted amounts are estimates and carry the rate date and source.
- Rate limits: 120 requests/min per IP by default; auth 10/min; password reset 3/min; review posting 5/min and 5/day per user.
- There are no commerce endpoints (cart, order, checkout, payment, reservation, delivery).

## Public (guest)

| Method | Path | Notes |
| --- | --- | --- |
| GET | `/health`, `/health/live` | Readiness (DB, cache, integrations) and liveness |
| GET | `/meta` | Countries, languages, currencies, forms, routes, services, ATC groups |
| GET | `/fx/rates` | Latest reference rates (`isFallback` when only development rates exist) |
| GET | `/medicines/search` | `q, ingredients (csv, all must match), manufacturer, atc, form, route, prescription, country, strength ("400 mg"), packageSize, barcode, registrationNumber, hasPrice, sort (relevance/name/price_asc/price_desc/rating), page, pageSize ≤ 50, currency` |
| GET | `/medicines/suggest?q=` | Medicines, ingredients (incl. synonyms), manufacturers, ATC classes |
| GET | `/medicines/popular`, `/medicines/popular-searches`, `/medicines/categories` | From anonymous analytics |
| GET | `/medicines/{id}` | Detail with registrations, documents, safety sections and provenance |
| GET | `/medicines/{id}/similar` | Products sharing a moiety, with composition class |
| GET | `/medicines/{id}/prices?currency&country` | Offers, conversions, per-unit price, availability, staleness, history, countries without data |
| POST | `/compare` | `{ medicineIds: string[2..6], currency? }` → summaries, `ComparisonResult`, best price per medicine. `?save=false` skips history |
| GET | `/pharmacies` | `q, lat, lng, radiusKm, city, postcode, country, openNow, services (csv), minRating, verifiedOnly, sort, page, pageSize` |
| GET | `/pharmacies/{id}?lat&lng` | Profile with hours, services, sub-ratings, verified flags, provenance |
| GET | `/pharmacies/external/google?lat&lng&radiusKm` | Live Google Places results (not stored); 503 `PROVIDER_NOT_CONFIGURED` without a key |
| GET | `/medicines/{id}/reviews`, `/pharmacies/{id}/reviews` | Published reviews + stats (`average`, `count`, `distribution`) |

## Auth

`POST /auth/register` · `POST /auth/login` · `POST /auth/refresh` · `POST /auth/logout` · `POST /auth/logout-all` · `POST /auth/forgot-password` (always 202) · `POST /auth/reset-password` (revokes all sessions).

## Signed-in user (`/me`)

Profile (`GET/PATCH /me`), preferences (`PATCH /me/preferences`), favourites (`GET/POST/DELETE /me/favorites`), search history, comparison history, recently viewed, notifications (`GET`, `POST /read`), push tokens, **GDPR export** (`GET /me/export`) and **account deletion** (`POST /me/delete` with password). Reviews: `POST /medicines/{id}/reviews`, `POST /pharmacies/{id}/reviews`, `POST /reviews/{id}/helpful` (toggle), `POST /reviews/{id}/report`, `DELETE /reviews/{id}` (own).

## Admin (`/admin`, role-based)

| Area | Roles | Endpoints |
| --- | --- | --- |
| Overview | MODERATOR, EDITOR, ADMIN | `GET /admin/overview` |
| Catalogue | EDITOR, ADMIN | medicines CRUD, `PUT …/ingredients`, packages, registrations, synonyms, `GET /admin/medicines/duplicates`, `POST …/merge`, ingredients, manufacturers, forms |
| Pharmacies | EDITOR, ADMIN | CRUD, `PUT …/hours`, `PUT …/services` |
| Prices & availability | EDITOR, ADMIN | `GET /admin/prices?stale`, `PATCH /admin/prices/{id}` (snapshot written), `GET /admin/offers/{id}/history`, `POST /admin/prices/mark-stale`, availability list/create |
| Moderation | MODERATOR, ADMIN | reviews queue, `PATCH /admin/reviews/{id}`, reports, `PATCH /admin/reports/{id}` |
| Users | ADMIN | list, role/status changes (self-demotion blocked), audit activity |
| Integrations | EDITOR (ADMIN to configure) | list with readiness, `PATCH`, `POST …/sync`, logs, country coverage |
| Analytics | EDITOR, ADMIN | `GET /admin/analytics?days=` |
| Audit | ADMIN | `GET /admin/audit-logs` |

Every admin mutation writes an `audit_logs` row with actor, before/after and IP.

A Bruno/Postman collection can be generated by importing `docs/openapi.json`.
